Curated slideshows and carousels for your brand on autopilot

Wavegrain makes curated TikTok slideshows and Instagram carousels for your brand. It writes and designs every slide from your brand and your photos, then schedules and posts them for you.

AI agents can use Wavegrain through its hosted MCP server.

  • wavegrain.com - the app
  • MCP server - connect Claude, ChatGPT, Cursor and other agents
  • Developer docs - API and OpenAPI file
  • wavegrain-mcp on GitHub - skill and plugin files
